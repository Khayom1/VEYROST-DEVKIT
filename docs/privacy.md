# Privacy

VEYROST-DEVKIT is designed to run locally.

- It does not require an account, API key, analytics service, or network connection to scan a directory.
- Repository file contents are processed by the local Node.js process.
- Reports are written only when the operator supplies an output path.
- The scanner does not intentionally collect or transmit personal information.

The operator is responsible for protecting local reports, especially when they include file paths or security findings. Verify the exact output destination before sharing a report.
