# Security Policy

## Supported versions

Security fixes are provided for the latest version on the default branch.

## Reporting a vulnerability

Please do not publish credentials or exploitable vulnerability details in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available. Include affected files, reproduction steps, and impact.

## Scanner limitations

VEYROST-DEVKIT performs heuristic pattern checks only. A clean report does not prove that a repository is secure. Rotate any credential that may have been exposed.
